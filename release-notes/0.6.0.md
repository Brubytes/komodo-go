Manage more of your Komodo environment from your phone, with resource creation, batch operations, deeper monitoring, and searchable logs.

## New

- Create stacks, deployments, servers, actions, and procedures from templates, copies, or full forms.
- Copy, rename, delete, and edit metadata or tags for supported resources.
- Run batch operations and see a separate result for each resource.
- Review resource sync plans and file changes before applying updates.
- Search server and container logs with reusable filters.

## Improved

- Monitor server health, processes, CPU, memory, disk, and network activity with adjustable intervals.
- See resource health and active work in the Ops Pulse dashboard.
- Check for image updates, inspect execution output, and use expanded container controls.
- Enjoy clearer labels and controls in dark mode.

## Fixed

- Code editors and resource names preserve exactly what you type, without unwanted iOS text substitutions.
- Action feedback distinguishes submitted requests from completed results and reports failures correctly.
- Resource statuses refresh more reliably after deployments, stops, and restarts.

Requires iOS 15 or later. Some operations depend on your Komodo version and permissions.

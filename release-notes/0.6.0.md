Komodo Go 0.6.0 expands the app into a fuller mobile operations console, with new resource-management workflows, deeper monitoring, and faster troubleshooting.

## Highlights

- Create stacks, deployments, servers, actions, and procedures from templates, copies, or full configuration forms.
- Copy, rename, delete, and update metadata or tags for supported resources.
- Select multiple resources and run batch operations with a clear result for every item.
- Review resource sync plans, inspect file changes, and choose which updates to apply.
- Check for image updates, start updates, and inspect complete execution output and configuration changes.
- Search server and container logs with reusable filters.
- Monitor server health, processes, CPU, memory, disk, and network activity with adjustable intervals.
- See resource health and active work at a glance in the new Ops Pulse dashboard.
- Inspect richer container details and use expanded lifecycle controls.

## Reliability

Resource lists, details, statuses, recent updates, and container information now refresh automatically after actions, reducing stale state and manual reloads.

Some advanced operations require a compatible Komodo version and sufficient server permissions.

## Compatibility

This release requires iOS 15 or later.

Komodo Go 0.8.1 fixes stacks that wouldn't open on Komodo 2.x and makes refreshing calmer across the app.

## Fixed

- Stacks with extra env files open again on Komodo 2.x.
- Builder settings show their current values on Komodo 2.x, and saving them no longer loses changes.
- Server terminal settings, server addresses, sync change lists, procedure steps and alerter details show the right values on Komodo 2.x.
- Saving an action with key-value arguments no longer fails.

## Improved

- Refreshing keeps what's on screen instead of flashing back to a loading state. A thin bar shows progress, and a failed refresh shows a banner with Retry.
- Pull to refresh waits until the new data has arrived.
- Changes you're making in an editor are kept while data refreshes in the background.
- New updates and alerts no longer push the list while you're scrolled down; tap "new updates" to see them.
- Servers, stacks and deployments use the same filters as the other lists.
- If Komodo sends data this version can't read, the error names the field, and one bad item no longer empties a whole list.

Requires iOS 15 or later. Some operations depend on your Komodo version and permissions.
